### Added

- **The linkmo copier template.** It turns a LinkML schema and a YAML directory or Python object of records into a click command line, a FastAPI API with an OpenAPI 3.1 contract, a Datasette browse build, gen-doc pages with examples, and tests that hold both doors to one answer; it reads its defaults from the `.linkml/` sidecar's answers and writes nothing under `.linkml/`.
